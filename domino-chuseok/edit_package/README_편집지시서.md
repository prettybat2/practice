# 추석 도미노 쇼츠 — 편집 패키지

> 이 폴더만 있으면 편집할 수 있게 정리했습니다. GPT 등 다른 편집자에게 폴더째 넘기면 됩니다.
> 완성본 예시: `final/domino_chuseok_60s.mp4` (Claude가 `scripts/edit_video.py`로 자동 편집한 버전)

## 1. 최종 규격

- 세로 9:16, 30fps, 약 60초 (쇼츠)
- 미리보기 클립은 540×960 (클라우드 CPU 렌더). PC에서 `scripts/render_all_clips.bat`을 돌리면 **같은 파일 이름**으로 1080×1920 고화질이 덮어써짐 → 편집을 그대로 다시 하면 됨

## 2. 폴더 구성

| 폴더 | 내용 |
|---|---|
| `clips/` | 장면별 영상 (소리 없음) |
| `audio/` | 장면별 도미노 소리 (영상과 **같은 길이, 0초부터 맞춰져 있음**) + `bell.wav` 종소리 |
| `final/` | 완성본 |
| `../assets/chuseok_cats.png` | 원본 그림 (마지막 전환용) |

## 3. 클립 설명

| 클립 | 내용 | 볼거리 |
|---|---|---|
| `scene01_marble` | 분홍 송편 구슬이 황동 나선 레일 → 유리 깔때기에서 소용돌이 → 시소에 떨어짐 → 첫 도미노 | 시소에 떨어지는 순간 (약 9.6~11초) |
| `scene02_stairs_bridge` | 커지는 무지개 줄, S자 → U턴 → 계단 오르기 → 다리 → 계단 내려가기 (앞머리를 따라가는 카메라) | 계단 구간 |
| `scene02b_overview` | 같은 장면을 높이서 본 부감. 줄이 자기 줄 위 다리로 교차하는 게 한눈에 보임 | |
| `scene03_pyramid` | 쐐기로 넓어지는 줄 → 3층 피라미드 붕괴 | 붕괴 (약 1.8초~) |
| `scene04a_yut_front` | 네 갈래 줄이 윷가락 4개로 다가감 (앞에서 낮게, 윷가락 등만 보임) | |
| `scene04b_yut_top` | 위에서: 윷가락 4개가 모두 X무늬 면으로 쓰러짐 = **"윷!"** | 공개 순간 |
| `scene05_moon` | 위에서 본 나선 필드. 쓰러지며 황금빛 보름달이 드러남 | 달 완성 |
| `scene06_y_split` | Y자 분기 → 두 갈래가 계단 → 분홍·연두 구슬을 경사로로 밀어냄 | 분기 순간 |
| `scene07a_wall_fall` | 두 구슬이 그림 벽 양 모서리를 동시에 침 → 금색 급전선 → V자로 그림이 드러남 (3,100개) | 모서리 타격, V자 |
| `scene07b_wall_reveal` | 다 쓰러진 그림 벽을 위에서 (한복 고양이 셋) | |

## 4. 권장 타임라인 (60초)

| 순서 | 클립 | 구간(초) | 속도 | 메모 |
|---|---|---|---|---|
| 1 | scene01_marble | 0–5 | 1.6배 | 나선 레일 빠르게 |
| 2 | scene01_marble | 5–9.6 | 1배 | 깔때기 소용돌이 |
| 3 | scene01_marble | 9.6–11.2 | **0.5배 슬로모션** | 시소 |
| 4 | scene01_marble | 11.2–14.5 | 1배 | 첫 줄 |
| 5 | scene02_stairs_bridge | 0–4.5 | 1.3배 | |
| 6 | scene02b_overview | 0–2.5 | 1배 | 교차 부감 |
| 7 | scene02_stairs_bridge | 4.5–7.6 | 1배 | 계단 |
| 8 | scene03_pyramid | 0–1.8 | 1배 | |
| 9 | scene03_pyramid | 1.8–4.0 | **0.5배** | 붕괴 |
| 10 | scene04a_yut_front | 0–2.3 | 1배 | |
| 11 | scene04b_yut_top | 0.4–3.6 | 1배 | "윷!" |
| 12 | scene05_moon | 0–13 | 2배 | |
| 13 | scene05_moon | 13–15 | 1배 | 달 완성 |
| 14 | scene06_y_split | 0–4.3 | 1배 | |
| 15 | scene07a_wall_fall | 0–3 | **0.5배** | 모서리 타격 |
| 16 | scene07a_wall_fall | 3–11 | 1배 | V자 공개 |
| 17 | scene07b_wall_reveal | 0–3 | 1배 | |
| 18 | 원본 그림 | 5초 | — | 흐린 확대 배경 위에 원본, 천천히 확대(1.0→1.18), **종소리** |

- 장면 사이: 0.35초 크로스페이드
- 슬로모션은 프레임 복제 대신 **움직임 보간**(ffmpeg `minterpolate`) 권장
- 소리: 각 구간에서 같은 이름의 `audio/*.wav`를 같은 구간으로 자르고 같은 속도로 (피치 유지)
- 그림 벽 공개 → 원본 그림은 1초 정도 부드럽게 디졸브
- 선택: 배경음악(가야금·해금 느낌의 잔잔한 곡)을 도미노 소리 아래 -18dB 정도로

## 5. 자동 편집 다시 하기

`scripts/edit_video.py`의 `TIMELINE`만 고치고 실행 → `final/domino_chuseok_60s.mp4`
(필요: Python + `pip install imageio-ffmpeg`)
