# 추석 도미노 영상 프로젝트 브리프

> 이 파일은 Claude Code가 이 폴더를 열면 자동으로 읽는 프로젝트 브리프입니다.
> 작업자: 루이 (편집디자이너, 파이썬·JSX 자동화 경험 있음). 대답은 항상 존댓말로 합니다.

## 1. 목표

Blender 물리 엔진으로 "구슬이 굴러가 도미노를 쓰러뜨리고, 거대한 도미노 벽이 넘어가면서 추석 그림이 드러나는" 세로 쇼츠 영상을 만든다.

- 참고 레퍼런스: YouTube TM Domino 채널 "AMAZING Rainbow Dominoes! | Satisfying Domino Screen Link" (실사 도미노 스크린)
- 최종 그림: `assets/chuseok_cats.png` — 한복 입은 고양이 셋, 문구 "즐거운 추석 보내고 계신가요?"
- 규격: 1080×1920 (9:16), 30fps, 약 20초
- 원하는 느낌: 다채롭고(무지개색), 다이나믹하고(구슬·분기·슬로모션), 도미노가 **실제로 부딪혀서** 쓰러질 것 (닿기 전에 혼자 쓰러지면 안 됨)

## 2. 확정된 구성 (v4 기준)

`reference/v4_composition_reference.mp4`가 구성 참고용 영상이다. 이건 Blender가 아니라 파이썬으로 흉내 낸 그래픽이라 물리·그림자가 가짜다. **구성과 흐름만 참고**하고, Blender에서는 진짜 물리로 다시 만든다.

1. **빨간 구슬**이 받침대 위 경사로를 굴러 내려와 첫 도미노를 친다 → 슬로모션
2. 작은 도미노에서 점점 커지는 **무지개 줄**이 S자로 달리다가 **Y자로 두 갈래** 분기 (왼쪽 빨강→노랑, 오른쪽 청록→파랑)
3. 각 갈래 끝 도미노가 **분홍 구슬 / 하늘색 구슬**을 밀어낸다
4. 두 구슬이 도미노 벽의 **양쪽 아래 모서리를 동시에** 때린다 → 슬로모션
5. 벽 앞의 **금색 급전선 도미노**가 가로로 연쇄하며 각 세로줄을 밀고, 쓰러짐이 양쪽 모서리에서 V자로 위를 향해 퍼진다
6. 벽 도미노의 한쪽 면에 그림 픽셀색이 칠해져 있어, 넘어가면 무지개 벽이 추석 그림으로 바뀐다
7. 다 쓰러지면 원본 그림으로 부드럽게 전환 + 종소리

(이전 버전에서 나온 의견: 가운데보다 **모서리에서 시작하는 게 더 효과적**, 도미노는 **더 다채롭게**.)

## 3. 작업 환경

- Windows, **Blender 5.0 계열** (무료, blender.org)
- 그래픽카드 **AMD Radeon RX 9060 XT** (RDNA4)
  - 기본 렌더러는 **Eevee** (빠르고 이 장면에 충분)
  - 사실적인 유리구슬 컷이 필요할 때만 Cycles + **HIP** (Preferences → System → HIP)
- 명령줄 실행 예 (경로는 설치 버전에 맞게 확인):
  `"C:\Program Files\Blender Foundation\Blender 5.0\blender.exe" -b -P scripts\파일.py`
  - `-b`는 창 없이 실행. 물리 검증은 이걸로, 렌더는 `-a`(애니메이션) 또는 특정 프레임만 `-f 번호`

## 4. 물리 설정에서 이미 배운 것 (중요)

- `bpy.ops.object.transform_apply()`는 기본값이 **위치·회전·크기 모두 적용**이다. 크기만 적용하려면 반드시
  `transform_apply(location=False, rotation=False, scale=True)`.
  이걸 틀리면 모든 도미노의 충돌 판정이 원점에 겹쳐 **첫 프레임에 폭발하듯 날아간다.**
- 구슬이 도미노 아랫부분을 치면 발이 밀려 **도미노가 뒤로 넘어진다.** 해결한 값:
  - 구슬 반지름 0.3, 질량 0.3 / 도미노 1.0×0.5×0.15, 질량 0.2, 마찰 0.8 / 바닥 마찰 0.8
  - 도미노 간격 0.6
- 강체 월드: `substeps_per_frame = 20`, `solver_iterations = 30`
- 도미노 1.0 높이는 실제 1m 스케일이라 쓰러짐이 느리다. 속도감이 필요하면 스케일을 줄이거나 중력/시간 배율을 조정.
- `scripts/domino_test.py` = 검증 완료된 기본 테스트 (구슬 + 도미노 10개, 끝까지 연쇄 확인됨)

## 5. 작업 방식

1. 스크립트를 수정하면 **먼저 `-b`로 물리만 돌려서** 모든 도미노가 앞으로 쓰러졌는지 수치로 확인한다 (각 도미노의 기울기 각도를 프레임별로 출력).
2. 통과하면 저해상도(예: 540×960)로 몇 프레임만 렌더해 `renders/`에 저장하고 직접 확인한다.
3. 괜찮으면 루이에게 보여 주고 방향을 확인받은 뒤 본 렌더.
4. 렌더 결과물은 `renders/` 폴더에 저장.
